# 月相能量账本

一个单文件网页 app：记录每天的饮食摄入和运动消耗，并结合月经周期做分析。

- 周期表盘：当前周期第几天、所处阶段（经期 / 卵泡期 / 排卵期 / 黄体期）和对应建议
- 今日能量：基础代谢（Mifflin-St Jeor）× 日常活动 + 运动消耗（MET × 体重 × 时长），黄体期自动 +6% 基础代谢
- 趋势图：30/60/90 天摄入 vs 总消耗，底部色带标出周期阶段，点击某天可跳转记录
- 分阶段对比：各阶段日均摄入、运动、盈亏，并给出文字洞察
- 周期日历：标记经期，自动计算平均周期长度，预测下次经期和排卵日
- AI 教练：记录后即时点评、点评今天、分析最近一个周期、生成明天的计划、自由提问、拍照识别食物热量
  - 在 claude.ai 打开时，使用你自己的 Claude 账号，不需要 API Key
  - 在本地打开 `index.html` 时，填入 Anthropic API Key 即可（Key 只保存在本机浏览器）
- 首次打开的引导：填写身高、体重、年龄、目标（默认「减脂保肌」，蛋白质 2.0 g/kg）、上次经期，可选导入 WHOOP
- AI 饮食识别：打一句话描述吃了什么（写清份量），AI 估算每一项的热量、蛋白质、碳水、脂肪并给一句总结；确认前可以勾选、改数字
- 蛋白质追踪：每项食物可填蛋白质克数，首页显示今日蛋白质 / 目标
- WHOOP 导入：上传 WHOOP 导出的 zip 或 CSV（physiological_cycles、workouts、sleeps、journal_entries）
  - 已结束的日子用 WHOOP 实测消耗替代公式估算，训练自动记入运动
  - 恢复、HRV、静息心率、皮肤温度、睡眠、Strain 按周期阶段对比，并交给 AI 教练参考
  - 列名做了宽松匹配，兼容 WHOOP 不同版本的导出格式
- 今天状态（默认折叠）：心情 1–5 分、压力/焦虑等标签、想喝酒的程度、喝了几杯
  - 心情 ≤ 2 分的日子进入温和模式：隐藏热量缺口，只提醒吃饱、喝水、早睡
  - 连续 3 天以上心情很低时，提醒找信任的人或拨打香港「情绪通」18111
- 无酒精记录：距离上次喝酒的天数、本月没喝的天数、最长连续纪录、最近 30 天格子（合并手动记录和 WHOOP 日志）
- 想喝酒时的急救面板：10 分钟呼吸陪伴、可以马上做的小事、自己写的“为什么不喝”、香港求助热线（18111 / 2389 2222 / 999）
- 化验记录对比表：每个项目一行，每次复查一列，数值并排；偏高橙色、偏低蓝色，显示和上次相比的变化（数值和百分比）；支持一次粘贴多行导入
- 每日最低摄入（默认 1450 kcal）和给 AI 教练的背景说明（只存在本机浏览器）
- 「我的资料」默认折叠并加密码锁：第一次展开时设密码，收起或刷新后自动锁上；忘记密码可以重设，但会清空健康背景（这是本机的隐私锁，不是加密）
- 数据保存在浏览器 localStorage，可复制备份 / 粘贴恢复

- 顶部 100 天倒数：第几天、还剩几天、100 格进度，可改开始日期和目标；每天一句中英双语、标明出处的激励语（个人成长、健康、亲密关系、运动），可换一句
- 页面分为「今天 / 分析 / 我的」三个标签页。首页顺序：100 天倒数与激励语 → 今日饮食推荐 → 今日训练 → 饮食记录 → 问答（AI 教练）→ 周期与热量概览 → 本周训练 → 今天状态
- 经期记录（首页最上方）：一键标记今天来月经 / 经期结束，可补记其他日期，记录流量和疼痛，有保存确认和撤销
- 热量：每日目标摄入不把运动加回来（静息消耗 + 黄体期 + 目标差）；显示净摄入（已吃 − 运动）和实际热量差（总消耗 − 已吃），按是否达到目标差用不同颜色标出
- 今日饮食推荐：三餐 + 加餐，按当天热量目标（含计划训练消耗、黄体期）自动调整主食份量，列出每项热量和蛋白质；可「换一个」、一键「按推荐吃了，记录」，吃的不一样时点「我吃的不一样」输入实际吃了什么，AI 分析后确认记录为这一餐，或让 AI 按个人背景定制一套；默认不含乳制品
- 核心目标：减脂增肌——翘臀和强大的臀部力量、薄而有型的背、细腿细腰
  - 训练计划与动作库（默认折叠）：翘臀 3 次、宽肩 2 次、平腹核心 3 次的打卡；每个部位 4 套训练组合（翘臀：A 力量日 / B 增肌日 / C 居家 / D 经前轻量；以髋主导动作为主、少练大腿前侧；背部练线条不堆厚度；腰腹不做负重侧弯），每个动作写明组数×次数、休息时间和动作要点，按周期阶段和 WHOOP 恢复自动推荐当天用哪套
  - 今日打卡总览：完成度圆环、完成组数、总训练量（kg）、用时、每个动作进度，本周 7 天打卡条
  - 一周课表：每周 3 / 4 / 5 天力量 + 2 天有氧日 + 休息日（默认 4 天：周一臀 A、周二肩背 A、周三有氧、周四臀 B、周五肩背 B、周六有氧、周日休息），打卡条显示整周计划和完成情况；周期和恢复只调整当天强度
  - 有氧日：有氧和力量分开在不同的日子，11 种可选（上坡快走、椭圆机、划船机、爬楼梯机、低阻力单车、游泳、Zone 2 慢跑、跳绳间歇、舞蹈、行山、饭后散步）
  - 训练量按研究设计：每个动作 2–4 组，每次目标部位约 10–15 个有效组，组间休息较短；「为什么这样设计」说明卡列出依据（Pelland 2025、Schoenfeld 2016/2017/2019、Roberts 2020、Hunter 2014、Lundberg 2022、McNulty 2020、Kissow 2022 等）
  - 每个动作都给出重量：没填重量基础时按体重估算并标「估算」，自重动作写明「自重」或弹力带
  - 撤销与确认：勾选、完成训练、记录餐食等操作后 8 秒内可撤销，已完成的训练和已记录的餐也能撤销；训练安排、饮食计划、今天状态、我的资料都有确认/保存按钮并显示确认时间
  - 今日训练：每天自动安排一个部位（按本周进度、昨天练了什么、周期和 WHOOP 恢复），含热身、主项递增热身组、每组建议重量、可勾选并修改实际重量和次数、组间休息倒计时、腰腹收尾，约 60–75 分钟；完成后记入运动，并在实际表现超过估算时自动更新重量基础
  - 进度计划：从第一次填重量起，按周计算每个动作应到的重量（卵泡期/排卵期正常加重，黄体期前段和经期加一半，经前一周不加），今日训练显示「进度参考」，重量基础表显示现在 / 4 周后 / 100 天结束的主项工作重量
  - 我的重量基础：填各主项最近一组的重量×次数，按 Epley 公式估算 1RM，每个训练动作显示建议重量（留约 2 次余力）；显示臀推力量是体重的几倍
  - 一周怎么排：每周 3 / 4 / 5 天的组合练法
  - 身材进度：体重、腰围、臀围、肩围、腰臀比、肩腰比，起点对比最近
  - AI 教练所有建议围绕这三个目标，并引用内置证据库里的 16 篇研究（均在 PubMed 核实：蛋白质、训练量与频率、月经周期与训练/饮食、局部减脂、睡眠、酒精、减重速度、女性能量不足等），回答末尾自动列出 DOI 链接
  - 「查 PubMed」：通过你 claude.ai 账号的 PubMed 连接器实时检索（AI 先生成英文检索词 → 搜索 → 读取摘要 → 按摘要回答并标 [P#]），约 30–90 秒；需要在 claude.ai 连上 PubMed 连接器并允许页面使用，新增「今天练什么」

- 界面参考苹果官网：系统字体、浅灰底白卡片、苹果蓝胶囊按钮、毛玻璃标签栏，支持深色模式

直接用浏览器打开 `index.html` 即可。首次打开显示示例数据，点“清空示例，开始记录我的数据”开始使用。

数字均为估算，不构成医疗建议。

### 更新：上肢综合 + 饮食推荐与记录合并
- 「肩背」扩展为「上肢综合 · 重点练背」（背阔、背部轮廓 + 少量肩、胸、手臂），每次力量训练约 60 分钟（含热身和腰腹收尾），有氧日约 45 分钟。
- 课表每周 2 天完全休息：默认 4 天力量 + 1 天有氧；或 3 天力量 + 2 天有氧。有氧分组可选（低冲击、户外、心肺挑战等）。
- 饮食推荐和饮食记录合并成一个板块：每餐点「吃了，记录」即完成记录，顶部显示早 / 午 / 晚进度；零食饮料在同一板块补记。
- 其他运动记录移到「今日训练」下方，默认折叠。
- 训练选择改为苹果风分段控件 + 组合卡片；力量日不再显示有氧相关内容。

### 更新：每天手动同步 WHOOP
- 首页经期卡片下方新增「今天的 WHOOP」卡片：起床后填恢复 %、HRV、静息心率、睡眠，以及昨天的 Strain 和消耗（都可空着），约 20 秒。
- 确认后：恢复圆环按 WHOOP 的绿 / 黄 / 红显示；训练还没开始或确认时，会按新恢复值重新安排（低于 34% 换轻量）；昨天的消耗替代估算，用于昨天的热量差。可撤销，可修改。
- 之后上传 WHOOP 导出的 zip 时，正式数据会覆盖手动填的数字。

### 更新：AI 全天饮食分析 + AI 运动记录
- 饮食板块新增「一句话告诉 AI 今天吃了什么」：AI 按餐次拆分（没吃 / 不吃某餐记为 0，按推荐吃的直接用推荐内容，零食饮料单独加上），预览可改数字，确认后一次记录，可撤销。
- 每张餐卡新增「没吃」按钮：记为 0 kcal，餐卡收起，早午晚进度点显示为划掉；可撤销。
- 在记录列表里删掉某餐的最后一项，这餐会自动回到未记录状态。
- 其他运动记录改为一句话描述，AI 拆分运动、估算时长和消耗（按体重和 MET），可改后确认；手动选择保留为备用。

### 更新：训练动作一键完成、换动作、删除
- 今日训练去掉热身清单和主项热身组。
- 每个动作下方新增：「✓ 全部做完」一键勾完所有组并填好建议重量和次数（再点可取消）；「换动作」下拉列出同类替换动作（同一部位、同类发力优先）；「删除」今天不做这个动作（可恢复）。所有操作都能撤销。
- 删除或替换后，预计时长、打卡汇总和力量纪录都按实际动作计算。
- 训练时长按“最大收益 + 效率”设计：力量 45–55 分钟，不为凑时间加组；课表显示每个组合的实际预计时长；「为什么这样设计」更新为每周各部位的实际组数。
