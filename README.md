# 月相能量账本

一个单文件网页 app：记录每天的饮食摄入和运动消耗，并结合月经周期做分析。

- 周期表盘：当前周期第几天、所处阶段（经期 / 卵泡期 / 排卵期 / 黄体期）和对应建议
- 今日能量：基础代谢（Mifflin-St Jeor）× 日常活动 + 运动消耗（MET × 体重 × 时长），黄体期自动 +6% 基础代谢
- 趋势图：30/60/90 天摄入 vs 总消耗，底部色带标出周期阶段，点击某天可跳转记录
- 分阶段对比：各阶段日均摄入、运动、盈亏，并给出文字洞察
- 周期日历：标记经期，自动计算平均周期长度，预测下次经期和排卵日
- AI 教练：记录后即时点评、点评今天、分析最近一个周期、生成明天的计划、自由提问、拍照识别食物热量
  - 在 claude.ai 打开时，使用你自己的 Claude 账号，不需要 API Key
  - 在本地打开 `index.html` 时，填入 Anthropic API Key 即可（Key 只保存在本机浏览器）
- 首次打开的引导：填写身高、体重、年龄、目标（默认「减脂保肌」，蛋白质 2.0 g/kg）、上次经期，可选导入 WHOOP
- AI 饮食识别：打一句话描述吃了什么（写清份量），AI 估算每一项的热量、蛋白质、碳水、脂肪并给一句总结；确认前可以勾选、改数字
- 蛋白质追踪：每项食物可填蛋白质克数，首页显示今日蛋白质 / 目标
- WHOOP 导入：上传 WHOOP 导出的 zip 或 CSV（physiological_cycles、workouts、sleeps、journal_entries）
  - 已结束的日子用 WHOOP 实测消耗替代公式估算，训练自动记入运动
  - 恢复、HRV、静息心率、皮肤温度、睡眠、Strain 按周期阶段对比，并交给 AI 教练参考
  - 列名做了宽松匹配，兼容 WHOOP 不同版本的导出格式
- 今天感觉怎么样：心情 1–5 分、压力/焦虑等标签、想喝酒的程度、喝了几杯
  - 心情 ≤ 2 分的日子进入温和模式：隐藏热量缺口，只提醒吃饱、喝水、早睡
  - 连续 3 天以上心情很低时，提醒找信任的人或拨打香港「情绪通」18111
- 无酒精记录：距离上次喝酒的天数、本月没喝的天数、最长连续纪录、最近 30 天格子（合并手动记录和 WHOOP 日志）
- 想喝酒时的急救面板：10 分钟呼吸陪伴、可以马上做的小事、自己写的“为什么不喝”、香港求助热线（18111 / 2389 2222 / 999）
- 化验记录对比表：每个项目一行，每次复查一列，数值并排；偏高橙色、偏低蓝色，显示和上次相比的变化（数值和百分比）；支持一次粘贴多行导入
- 每日最低摄入（默认 1450 kcal）和给 AI 教练的背景说明（只存在本机浏览器）
- 「我的资料」默认折叠并加密码锁：第一次展开时设密码，收起或刷新后自动锁上；忘记密码可以重设，但会清空健康背景（这是本机的隐私锁，不是加密）
- 数据保存在浏览器 localStorage，可复制备份 / 粘贴恢复

- 顶部 100 天倒数：第几天、还剩几天、100 格进度，可改开始日期和目标；每天一句标明出处的激励语（个人成长、健康、亲密关系、运动），可换一句
- 页面分为「今天 / 分析 / AI 教练 / 我的」四个标签页

直接用浏览器打开 `index.html` 即可。首次打开显示示例数据，点“清空示例，开始记录我的数据”开始使用。

数字均为估算，不构成医疗建议。
