# 求职工作流（精投）

用 Claude Code 帮你找工作：定标准 → 检索打分 → 求职信 → 薪资 → 归档 → 进度 → 面试准备 → 复盘。

每一步直接用中文说就行，Claude 会自动用对应的技能；也可以打斜杠命令。

所有岗位都在**精投看板**上（私有网页，只有你能打开，链接和数据结构见 `board.md`）：候选、已投递、面试中、Offer、已结束五列，每个岗位有内容匹配度和前景两个分数、下一步、时间线和材料（JD 全文、求职信、面试准备）。Claude 改了什么，看板马上更新；你在看板上改状态、写不投的原因、自己添加岗位，Claude 下次也会读到。

## 第一次使用

1. **保护隐私。** 岗位记录和材料在私有看板上，不受仓库影响。简历和筛选标准放在 `job-search/private/`；这个仓库现在是公开的，所以这个目录被 `.gitignore` 挡住，不会上传。
   - 在云端用（claude.ai/code 或手机）：会话结束后容器会被回收，`private/` 里的简历和标准会丢。把仓库改成私有后告诉 Claude，Claude 核实后就会开始提交保存。
     改法：GitHub 仓库页 → Settings → General → 最下面 Danger Zone → Change visibility → Private。
   - 在自己电脑上用（Claude 桌面端 → Code 模式 → 选这个文件夹）：文件留在本地，不需要改。
2. **发简历。** 把简历 PDF 发在对话里，或者直接粘贴文字。
3. **定标准。** 说「一起定求职标准」。Claude 会先读简历，说出对你的竞争力和方向的判断，再分几轮问你。这一步给的信息越多，后面越准：
   - 喜欢做、不喜欢做的具体工作内容和方向
   - 如实说能力缺口
   - 硬性条件：城市、职级、薪资下限、居家办公比例、签证
   - 不看好的行业、不考虑的公司

## 日常使用

| 步骤 | 你说 | 斜杠命令 | 得到什么 |
|---|---|---|---|
| 1 更新标准 | 「这个不合适，因为…」 | `/job-criteria` | 更新 `criteria.md` |
| 2 检索 | 「找工作」 | `/find-jobs` | 推荐表，按内容匹配度、前景两个维度打分 |
| 3 求职信 | 「给第 2 个写求职信」 | `/cover-letter` | `cover-letter.md` |
| 4 薪资 | 「这个岗位期望薪资填多少」 | `/salary-research` | 市场数据、建议数字、口头回答的说法 |
| 5 归档 | 「第 2 个已投递」 | `/job-applied` | 看板改成已投递，JD 全文存档 |
| 6 进度 | 贴邮件（带发件人信息） | `/job-status` | 更新状态，给回复草稿 |
| 7 面试准备 | 「帮我准备面试」 | `/interview-prep` | 面试官和公司调研、预测问题、反问问题，可以模拟面试 |
| 8 复盘 | 「刚面完，…」（越细越好） | `/interview-debrief` | 复盘记录、感谢信草稿 |

## 和自动投递系统结合

如果你另外用 Claude 做了自动投递（在 Mac 上找岗位、改简历、提交、记 `tracker.csv`），它投的岗位也可以进看板：

- **导入**：在看板上点「导入投递记录」，选 `tracker.csv`（或粘贴内容）。同一个岗位不会重复，看板上已经推进的状态不会被改回去。
- **自动同步**：把 `board.md` 里「自动同步」那一段加进自动投递技能，每投一个就直接写进看板。

两边共用一个看板后，这里检索时会跳过自动投递已经投过或跳过的岗位；收到面试邮件时，不管是哪边投的，都在看板上更新。

## 小贴士

- 刚开始多花点时间亲自看推荐结果，不合适的都说原因。反馈越多，推荐越准。
- 标准可以定得很严——目标是精投，不在不合适的岗位上浪费时间。
- 投完马上说「已投递」，JD 会被存档。很多岗位开始面试后就下线了。
- 贴邮件时带上发件人信息，面试准备要用。
- 面完趁热复盘，越细越好。
- 投递由你自己点提交，Claude 只准备材料。

## 文件

```
job-search/
├── README.md             这份说明
├── board.md              精投看板的链接、数据结构、和自动投递系统的同步方法
├── templates/
│   └── criteria.md       筛选标准模板
└── private/              你的资料（仓库公开时不会上传）
    ├── profile/          简历
    ├── criteria.md       筛选标准：检索的核心，随反馈更新
    ├── question-bank.md  面试题库
    ├── searches/         每次检索的完整记录
    └── applications/     材料的本地副本
```

规则写在仓库根目录的 `CLAUDE.md`，每一步的做法写在 `.claude/skills/`。

## 在云端用的限制

云端环境的网络策略可能拦截招聘网站（搭建时 LinkedIn、JobsDB、Glassdoor 都打不开）。Claude 还能用网页搜索找岗位，但读不了这些网站上的 JD 全文。解决办法：

- 在环境设置里放行这些域名：会话标题栏的云端环境菜单 → Edit → Network access；或者
- 把 JD 原文贴给 Claude。
