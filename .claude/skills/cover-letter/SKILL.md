# 写求职信

## 材料

1. JD：优先用 `private/applications/<文件夹>/JD.md`。还没存档就从链接读或请用户贴，并顺手按 `job-applied` 里的格式存下来，免得岗位下线。
2. 简历（`private/profile/cv.md`）——唯一的事实来源。
3. `criteria.md` 里的定位、核心竞争力、能力缺口和应对方式。
4. 公司：查 2–3 条能核实的信息（最近的项目、战略重点、在本地区的业务），只用有来源的。

## 写法

- 语言跟 JD，默认英文。300–400 词，一页。
- 结构：
  1. 开头：申请哪个职位；一句话说清「我能为这个岗位解决什么」（用 criteria.md 里的定位）；再给一个和这家公司有关的具体理由。不要用 "I am writing to apply for…" 这类套话开头。
  2. 两段证据：挑 JD 里最重要的 2–3 条要求，每条对应简历里一段真实经历，写清做了什么、结果如何（数字只用简历里有的）。用 JD 的关键词，但只用对用户属实的。
  3. 有明显缺口时，用一句话诚实处理（用 criteria.md 里写好的应对方式），不回避也不道歉。
  4. 结尾：简短，表达面谈意愿。
- 语气：自信、具体、不夸张。不用空洞的形容词（passionate、dynamic、results-driven 之类）。
- 称呼：JD 里有招聘经理名字就用名字，否则用 "Dear Hiring Team"。

## 自查（给用户之前逐句过一遍）

- 每个事实、数字、头衔、日期都能在简历里找到。
- 提到的公司信息都有来源。
- 公司名、职位名拼写正确；没有和这个 JD 无关的段落。

## 输出

1. 保存到 `private/applications/<YYYY-MM-DD_公司_职位>/cover-letter.md`（文件夹还没有就用今天的日期新建），文末列出参考的公司信息来源。
2. 在对话里给全文，并说明对应了 JD 的哪几条要求、缺口是怎么处理的。
3. 用户要改就改，改完覆盖保存。需要 Word 或 PDF 就导出。
